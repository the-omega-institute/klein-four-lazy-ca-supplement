# Supplementary material: Generation by lazy and invertible cellular automata over the Klein four-group

Supplementary material for E. Alcalá-Arroyo, A. Castillo-Ramírez, H. Ma and W. Zhang,
*Generation by lazy and invertible cellular automata over the Klein four-group*.

This repository contains a standalone Lean 4 / Mathlib formalization of the main membership criterion
(Theorem 1.1) and of the two cardinalities stated in the paper:

- `KleinFour.membership_iff`: a cellular automaton T lies in the monoid generated by the invertible and the lazy
  cellular automata if and only if it satisfies the criterion of Theorem 1.1;
- `KleinFour.membership_iff_orbits`: the same criterion in the orbit-image form used in the paper;
- `KleinFour.membership_card`: the generated monoid has 59,712 elements;
- `KleinFour.lazy_membership_card`: the monoid generated by the lazy maps alone has 4,007 elements.

All results depend only on the standard axioms `propext`, `Classical.choice` and `Quot.sound`
(see `axioms.log`); there is no `sorry` and no `native_decide`.

Build instructions and a description of the model are in `LEAN-README.md`
(Lean `leanprover/lean4:v4.33.0`, Mathlib `v4.33.0`).
